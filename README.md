# The Register Lab

An interactive x86-64 assembly course in the browser. Step through real instructions and watch values fly between registers, flags, the stack and memory.

- 8 lessons: registers, math & flags, loops, the stack, functions, memory, bits, and a sandbox
- Built-in simulator with plain-English explanations of every instruction
- "Predict it" quizzes, editable code, run/step controls with speed slider
- Light and dark themes, works on mobile

Single static `index.html`, no build step. Open it locally or deploy anywhere.
